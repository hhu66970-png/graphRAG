## 抽取字段评测

```bash
python scripts/eval_extraction.py
python scripts/calibrate_thresholds.py
```

参照集从教材中 375 味药的结构化字段解析得到，未经双人标注与仲裁。
原记录如下：

| 字段 | Recall@field | Prec@field 下界 |
|---|---:|---:|
| 性味 | 90.1% | 88.0% |
| 归经 | 78.6% | 90.9% |
| 功效 | 86.1% | 50.0% |
| 合计 | 85.2% | 69.0% |

主治、配伍与禁忌没有相同口径的字段参照。字段外抽到的合理事实也可能无法匹配参照，
因此 Precision 按下界解释；85.2% 是字段召回率，不是整体准确率。

`KG_FINAL_ACCEPT` 默认值为 `0.80`。原标定记录中，该值附近 Recall 从 85.6% 降到
85.2%，Prec 下界从 67.2% 升到 69.0%；继续提高到 `0.85` 时 Recall 降至 78.1%。
实体链接阈值 `0.94/0.84` 尚未在完整金标集上标定。

## 问答评测

- [检索题集](../eval/retrieval/README.md)：120 题，按固定 dev/test 划分，记录为已人工仲裁。
  当前评分覆盖路由、实体、谓词、拒答和页码；未实现排序 Chunk 的 `Recall@5`。
- [高风险题集](../eval/high_risk/README.md)：14 题，全部待人工仲裁。
  只计算可由响应与证据核对的指标，语义正确性与完整性返回 `not_measured`。

使用 `hash` 嵌入得到的结果只适合测试接口与流程，不作为检索质量结论。
普通生成回答尚未逐条校验模型结论与引文；高风险回答使用独立的程序核验。
OCR 噪声、条目识别遗漏与证据归属错误仍可能影响结果。
